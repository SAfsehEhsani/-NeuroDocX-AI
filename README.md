# NeuroDocX-AI
# Multimodal Gen AI- LLM Powered PDF Analyser &amp; Semantic Explainer

NeuroDocX is an advanced Generative AI-powered document analysis system built to extract, understand, and explain complex PDF content such as research papers, technical manuals, academic reports, and scientific documents. It leverages LLMs, RAG (Retrieval-Augmented Generation), and semantic search to answer user queries about documents in a natural, conversational format.

# 🎯 Project Objective
To build an intelligent document Question-Answering and summarization platform that:

Parses PDFs and extracts structured content.

Supports natural language querying over document data.

Delivers accurate, context-aware, and human-readable explanations.

Integrates multiple Large Language Models (LLMs) to provide hybrid reasoning and rapid inference.

# ⚙️ Key Features
📄 PDF Upload & Parsing – Easily upload and parse documents into chunks for semantic understanding.

🔍 RAG Pipeline – Combines local vector search (FAISS) and LLMs to produce high-quality, fact-based answers.

🤖 Multimodal LLM Integration – Routes queries through Groq (Mixtral), Hugging Face, or OpenAI/Claude for best-fit response generation.

🧠 Semantic Search – Indexes documents with embeddings and retrieves the most relevant chunks.

💬 Conversational UI – Interactive chat-like interface built with Streamlit.

🌐 Web-Augmented Q&A (Optional) – Adds external search for broader context using Serper.dev or other APIs.

# 🛠️ Tech Used

Component	Technology Used
📄 PDF Handling	PDFPlumber / PyMuPDF
🔍 Vector Search	FAISS
🧠 LLMs	Groq (Mixtral), Hugging Face Transformers
🔗 LLM Orchestration	LangChain
💬 UI	Streamlit
🔧 Backend Logic	Python
